# DNS Application

Приложение для управления DNS-серверами на удаленном компьютере через редактирование файла `/etc/resolv.conf`.

## Описание

Проект представляет собой клиент-серверную архитектуру:

- **Сервер**: Предоставляет gRPC API для управления DNS-серверами.
- **CLI-клиент**: Интерфейс командной строки для взаимодействия с сервером.

## Возможности

- Добавление нового DNS-сервера.
- Удаление существующего DNS-сервера.
- Получение списка всех настроенных DNS-серверов.
- Корректная обработка невалидных запросов и ошибок доступа к файловой системе.

## Сборка и запуск

### Генерация контракта

Для генерации контракта gRPC выполните следующую команду:

```bash
make all
```

### Сборка приложений

Для компиляции сервера и клиента выполните следующие команды:

```bash
go build -v -o ./bin/resolver resolver/cmd/app.go
go build -v -o ./bin/cli cli/cmd/app.go
```

### Запуск сервера

Сервер должен быть запущен перед использованием CLI-клиента. По умолчанию он слушает порт `:8080`.

```bash
sudo ./bin/resolver
```

### Использование CLI-клиента

После запуска сервера используйте следующие команды:

```bash
./bin/cli --help # посмотреть доступные команды
./bin/cli add <ip-адрес> # добавить DNS-сервер
# ./bin/cli add 8.8.8.8
./bin/cli delete <ip-адрес> # удалить DNS-сервер
# ./bin/cli delete 8.8.8.8
./bin/cli get # получить список добавленных DNS-серверов
```
